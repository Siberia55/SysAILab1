# Лабораторная работа №1. RAG-ассистент по документам

## 1. Описание проекта

RAG-ассистент предназначен для поиска информации в коллекции документов по тематике искусственного интеллекта.

Система использует подход Retrieval-Augmented Generation (RAG): преобразует документы и запрос пользователя в векторные представления, находит наиболее близкие фрагменты текста и формирует ответ на основе найденных фрагментов.

Если подходящая информация не найдена, система возвращает сообщение:

`Не нашёл информации по вашему вопросу`

## 2. Используемые технологии

- Python 3.13
- FastAPI — создание REST API
- Uvicorn — запуск веб-сервера
- Sentence Transformers — создание эмбеддингов
- `intfloat/multilingual-e5-small` — модель эмбеддингов
- ChromaDB — векторное хранилище
- PyMuPDF — чтение PDF-документов
- Pytest и HTTPX — автоматическое тестирование API

## 3. Структура проекта

- `app/` — приложение и основные модули RAG
- `data/` — документы для индексации
- `scripts/build_index.py` — построение векторного индекса
- `tests/test_api.py` — автоматические тесты API
- `requirements.txt` — зависимости проекта
- `.gitignore` — исключения для Git

## 4. Корпус документов

В каталоге `data/` находятся шесть учебных документов, подготовленных для лабораторной работы:

1. `01_artificial_intelligence.md` — искусственный интеллект.
2. `02_rag_overview.md` — принципы работы RAG.
3. `03_embeddings.md` — векторные представления текста.
4. `04_chunking.md` — разбиение документов на чанки.
5. `05_vector_database.md` — векторные базы данных.
6. `06_rag_evaluation.md` — оценка качества RAG-систем.

Документы представлены в формате Markdown и объединены общей тематикой — искусственный интеллект и технологии поиска информации.

## 5. Установка

Создайте и активируйте виртуальное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

## 6. Построение индекса

Из корневого каталога проекта выполните:

```powershell
python scripts/build_index.py
```

Скрипт загружает документы, разбивает их на чанки, создаёт эмбеддинги и сохраняет их в ChromaDB.

Используемый размер чанка — 400 токенов, перекрытие — 60 токенов.

## 7. Запуск API

```powershell
python -m uvicorn app.main:app --reload
```

После запуска документация API доступна по адресу:

http://127.0.0.1:8000/docs

## 8. Использование API

Основной метод:

`POST /ask`

Пример запроса:

```json
{
  "question": "Что такое RAG и как он работает?"
}
```

Ответ содержит:

- `answer` — текст ответа;
- `sources` — источники с именем файла, идентификатором чанка, оценкой сходства и расстоянием;
- `model_version` — название используемой модели эмбеддингов.

Если подходящая информация отсутствует, возвращается сообщение об отсутствии информации и пустой список источников.

## 9. Автоматические тесты

Запуск тестов:

```powershell
python -m pytest -v
```

Проверяются главная страница API, ответ на релевантный вопрос, отсутствие подходящей информации и валидация пустого вопроса.

Результат проверки: 4 теста пройдены успешно.

## 10. Ограничения

Система ищет информацию только в проиндексированных документах. Качество поиска зависит от содержания корпуса, модели эмбеддингов и установленного порога сходства.

Генерация ответа большой языковой моделью не используется: ответ формируется из найденных текстовых фрагментов.
