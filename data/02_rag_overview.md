# RAG: генерация с дополнением поиска

RAG (Retrieval-Augmented Generation) — подход, при котором языковая модель использует найденные документы для подготовки ответа на вопрос пользователя.

Типичная RAG-система состоит из двух основных этапов: поиска информации и формирования ответа. Сначала система находит фрагменты документов, связанные с вопросом. Затем найденные фрагменты передаются компоненту формирования ответа в качестве контекста.

RAG позволяет использовать сведения из собственной базы знаний без необходимости заново обучать языковую модель на каждом новом документе. Базу знаний можно обновлять отдельно от модели.

Качество RAG зависит от полноты корпуса, правильного разбиения документов на фрагменты, качества эмбеддингов и точности поиска. Если поиск возвращает нерелевантные фрагменты, итоговый ответ также может оказаться неправильным.

Для уменьшения числа неподтверждённых ответов система может проверять оценку релевантности найденных фрагментов. Если подходящей информации нет, следует сообщить пользователю, что ответ не найден в доступных документах.
