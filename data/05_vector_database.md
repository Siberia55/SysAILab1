# Векторные базы данных и ChromaDB

Векторная база данных предназначена для хранения векторов и поиска наиболее близких к запросу объектов. В RAG-системе такими объектами обычно являются фрагменты документов.

ChromaDB — инструмент для хранения коллекций данных, в которых текстовые фрагменты связываются с эмбеддингами и метаданными. Метаданные могут включать имя файла, идентификатор чанка и другие сведения об источнике.

Во время индексации приложение извлекает текст из документов, делит его на фрагменты, вычисляет эмбеддинги и сохраняет результаты в векторном хранилище.

При поступлении вопроса система вычисляет эмбеддинг запроса и ищет близкие векторы. Найденные фрагменты сортируются по релевантности и передаются следующему этапу обработки.

Для воспроизводимости индекса важно использовать согласованные настройки модели и разбиения текста. Если документы изменились или параметры обработки были изменены, индекс следует построить заново.
